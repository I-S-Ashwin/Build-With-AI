What MediSense Does

MediSense is a single-page health triage app. A user describes their symptoms in natural language or by voice. The Clinical NLP engine (or Gemini 1.5 Flash cloud) analyses the text, detects negation, extracts duration & severity, scores 116 clinical conditions, and responds with an empathetic differential assessment — home-care steps or a doctor referral. All data stays in localStorage. No account needed.

3 "To Change This, Start Here" Pointers

1

Change how AI responds to symptoms

Open clinical-nlp.js → DialogueManager.generate() (bottom of file). The response text templates are inline strings there. To adjust scoring weights (which condition ranks highest), edit DifferentialEngine.compute().

2

Add or edit a medical condition

Open knowledge-base.js. Each entry in MEDISENSE_KB is a plain object with condition, symptoms[], urgency, advice, and redFlags[]. Copy an existing entry and modify. No rebuild needed — reload the page.

3

Change the design / colours

Open style.css → the :root block at the top. The four Mondrian palette variables (--color-red, --color-yellow, --color-blue, --color-black) control every coloured element site-wide. Dark mode overrides are in the [data-theme="dark"] block.

How to Run Locally

# From the project root:
node server.js

# Then open:
http://localhost:3000

# No npm install needed — zero dependencies, plain browser JS.

Gemini API key is optional — the offline Clinical NLP engine covers all 116 conditions without any key. To use Gemini cloud, click the 🔑 API Key button inside the app and paste your key.
